After some interest from folks online, I decided to publish my [Emacs configuration](/emacs-config). As you'll see, it's all incredibly basic,
but maybe folks will find it useful. There are a few things missing, as I'm in a yearly-ish process of cleaning out and refreshing the cruft in my configuration. I'll add my configuration related to academic writing and research soon (funny because I don't do much of either these days), if that's something you're interested in and wondering about.

The documentation, too, needs a bit of work. The nice thing is that I've set this up to be served out of my own literate config files, so things will update publicly as I update them for myself. I'm still working on how to organize things on my site, but note that there are currently two fies:

-   [The literate configuration file itself.](/emacs-config) This is what is linked to in the menu.
-   [My template files.](/emacs-capture-templates) These are linked to in the capture template section of the config, but I'm just noting that in case it gets missed.

Again, this is both very simple and (necessarily?) incomplete. If you want more info or run into issues with anything you try to use, feel free to let me know on [Mastodon](https://mas.to/@rickwysocki).
